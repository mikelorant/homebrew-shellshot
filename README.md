# Mikelorant Shellshot

## How do I install these formulae?

`brew install mikelorant/shellshot/<formula>`

Or `brew tap mikelorant/shellshot` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mikelorant/shellshot"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
